# Your first Board

1. In the Library, choose **New board**, enter a name, and confirm. Select a
   project folder first if you want the Board filed there.
2. Write in the first Note. Use **New note** to add another idea. Drag cards to
   arrange them. Use the mouse wheel to zoom and right-drag the blank Board to pan.
3. Select two Notes or Images and use the connection command. Add a label to
   explain their relationship. Connectors currently join Notes and Images.
4. Try **Add image** or **Import reference file**. Imported files become managed
   copies; later editing the source file does not update the Board copy.
5. Watch the save status. **Save now / Ctrl+S** saves immediately. If a save
   fails, keep Vasmim open and use **Retry save** after checking disk/folder access.
6. Return to the Library, reopen the Board, and continue editing. Normal window
   close waits for pending saves. Forced termination and power failure can still
   lose changes not yet written.
7. Use **Export all boards** and **Verify backup folder** to create and check an
   independent backup. Use `.vasmim` export/import to move one Board.

Open **Help and shortcuts** from the Library or Board for controls. Overview,
Zoom to Fit, and Find help you relocate content. Undo/redo applies to the current
editing session; it is not a permanent version archive.

Optional organization: Shapes draw behind foreground cards; Groups collect
items; Scenes remember views. Start with Notes and connections before exploring
these controls. Click a YouTube thumbnail to open the video externally; drag its
bottom strip to move/select it.
