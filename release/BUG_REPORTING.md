# Report a problem

Report problems on the project's public issue page:
<https://github.com/racasan/vasmim/issues>.

Vasmim is a free hobby project provided as is. Reports are welcome, but no
reply, fix, or response time is promised. Vasmim never sends a report
automatically.

Include:

1. Application version and Windows edition/build/architecture.
2. What you expected and what actually happened.
3. The smallest repeatable steps, ideally using a disposable Board.
4. Exact error text and a sanitized screenshot if useful.
5. Whether saving, reopening, attachments, or export/import was involved.

Issues are public. Keep private Boards, documents, filenames, usernames, and
credentials out of them. A real Board is not required for a report. Do not
repeatedly retry saving over a damaged file; preserve its folder and an exported
backup. If saving fails, keep Vasmim open while checking free space and folder
access.

For a suspected security problem, use the repository's **Security** tab and
choose **Report a vulnerability** so the details stay private. If that option is
unavailable, open an issue that says only that you have a security report, and
do not post exploit details publicly.
