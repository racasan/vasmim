# Sample Boards

Three ready-made Boards to explore. They are the Boards shown in the
screenshots on the main page.

| File | What it shows |
| --- | --- |
| `01-the-last-lighthouse.vasmim` | A game story: world, characters, and connected plot beats, with concept art. Looks best in Dark mode. |
| `02-sunday-outside.vasmim` | A community campaign: visual reference, the brief, and a rollout plan. |
| `03-studio-website-launch.vasmim` | A website launch: a filled-in Kanban with decisions and launch checks. |

## Open them

1. Download the `.vasmim` files.
2. In Vasmim's Library, click the **Import portable board** button in the top
   bar and pick a file.
3. Open the imported Board. Each one has named Scenes; try the Scene list and
   the Walkthrough.

Importing adds a copy to your Library and does not change any of your own
Boards. Edit the samples freely, or duplicate one in the Library to keep the
original.

## About the content

Every project, person, date, and target in these Boards is fictional. The two
pictures were generated with an AI image tool for these examples; Vasmim
itself does not generate images. Like the rest of this repository, the sample
Boards are released under the BSD Zero Clause License.
